# Изображения бренда

Файлы в этой папке подхватываются автоматически: код проверяет наличие файла
на сборке и, если его нет, рендерит заглушку тех же пропорций. Менять код
при добавлении изображений не нужно.

## Что нужно добавить

| Файл                 | Размер           | Где используется                        | Статус |
| -------------------- | ---------------- | --------------------------------------- | ------ |
| `portrait.jpg`       | 1200×1500 (4:5)  | Главная, /about, Open Graph для /about  | TODO   |
| `youtube-banner.jpg` | 2560×1440 (16:9) | Главный блок страницы /media            | TODO   |
| `og-default.jpg`     | 1200×630         | Open Graph и Twitter/X по умолчанию     | Готово |
| `icon-512.png`       | 512×512          | Крупная иконка бренда                   | Готово |

## Требования

- **portrait.jpg** — реальная фотография Дмитрия Пятакова. Соотношение 4:5,
  вертикальная. Лицо не должно попадать под обрезку по краям.
- **youtube-banner.jpg** — реальный баннер YouTube-канала, без изменений:
  не перерисовывать, ничего не накладывать. Показывается целиком
  (`object-fit: contain`), поэтому важные элементы не обрежутся.

Изображения оптимизируются на лету средствами Next.js (AVIF/WebP), поэтому
исходники можно класть в хорошем качестве.

## Логотипы проектов

Опционально: `/public/images/projects/<slug>-og.jpg` — Open Graph страницы проекта.
Файлы для всех текущих проектов уже сгенерированы в фирменном стиле.
