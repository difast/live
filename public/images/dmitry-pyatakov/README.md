# Изображения бренда

Файлы в этой папке подхватываются автоматически: код проверяет наличие файла
на сборке и, если его нет, рендерит заглушку тех же пропорций. Менять код
при добавлении изображений не нужно.

Расширение значения не имеет — подойдёт `.jpg`, `.jpeg`, `.png`, `.webp`
или `.avif`. Важно только имя файла: `portrait` и `youtube-banner`.

## Что нужно добавить

| Файл                 | Размер           | Где используется                        | Статус |
| -------------------- | ---------------- | --------------------------------------- | ------ |
| `portrait.*`         | 1200×1500 (4:5)  | Главная, /about, Open Graph для /about  | TODO   |
| `youtube-banner.*`   | 2560×1440 (16:9) | Главный блок страницы /media            | TODO   |
| `og-default.jpg`     | 1200×630         | Open Graph и Twitter/X по умолчанию     | Готово |
| `icon-512.png`       | 512×512          | Крупная иконка бренда                   | Готово |

## Требования

- **portrait** — реальная фотография Дмитрия Пятакова. Соотношение 4:5,
  вертикальная. Лицо не должно попадать под обрезку по краям. Пока файла нет,
  первый экран собран как чисто типографская обложка, а на /about биография
  разворачивается в две колонки; с фотографией обе композиции переключаются
  на разворот «текст + портрет».
- **youtube-banner** — реальный баннер YouTube-канала, без изменений:
  не перерисовывать, ничего не накладывать. Показывается целиком
  (`object-fit: contain`), поэтому важные элементы не обрежутся.

Фотография также попадает в Schema.org как `image` сущности Person — но только
когда файл действительно выложен, чтобы не объявлять поисковым системам
несуществующее изображение.

Изображения оптимизируются на лету средствами Next.js (AVIF/WebP), поэтому
исходники можно класть в хорошем качестве.

## Логотипы проектов

Опционально: `/public/images/projects/<slug>-og.jpg` — Open Graph страницы проекта.
Файлы для всех текущих проектов уже сгенерированы в фирменном стиле.
